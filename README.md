# .github
Organization-wide defaults for True Bearing: contributing guide, security policy, issue and PR templates, and the public profile (`profile/README.md`).

The issue forms in `.github/ISSUE_TEMPLATE/` are a design sketch of the work units (feature, maintenance, support). Issues are disabled by design in this organization, so the forms are not in use yet. The forms set an issue type (`feature`, `maintenance`, `support`), so those types must exist at the organization level before the forms can work.

`CONTRIBUTING.md` says no approval is required while there is one maintainer. Revisit it, and `.github/CODEOWNERS`, when a second maintainer or a team is added.
